# CatchUp Company Website

This directory contains the source code for the official CatchUp landing page and marketing website.

It serves as the public face of the CatchUp app, providing potential users with an overview of the platform's features, the benefits of social health tracking, and direct links to sign up or log in to the main web application.

## Key Features

* **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
* **Feature Showcase:** Highlights the Apple Health integration, Health Score algorithm, and social leaderboards.
* **Call to Action (CTA):** Clear pathways guiding users to register and access the main CatchUp application.
* **SEO Optimized:** Structured for search engine visibility to drive organic traffic.

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (or React.js/Vite depending on your exact setup)
* **Hosting:** Designed to be easily deployed on static hosting platforms (e.g., Vercel, Netlify, GitHub Pages).
